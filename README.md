# Cenote Gardens

## Link del proyecto publicado

https://dulcet-arithmetic-4f11b2.netlify.app/

## Descripcion

Landing page para Cenote Gardens. El sitio presenta una propuesta visual para un proyecto inmobiliario o residencial, con secciones comerciales, contenido multimedia y experiencia enfocada en captacion de clientes.

## Tecnologias usadas

- Astro
- React
- Vue
- Tailwind CSS
- Sass
- Swiper
- Netlify

## Requisitos

- Node.js 18+
- npm
- Cuenta de Netlify para despliegue

## Retos tecnicos

- Combinar componentes de React y Vue dentro de un proyecto Astro.
- Configurar salida hibrida con adaptador de Netlify.
- Crear secciones visuales con carruseles e imagenes de alto impacto.
- Mantener rendimiento aceptable en una landing con carga visual importante.
